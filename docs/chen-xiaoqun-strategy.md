# 陈小群策略学习与优化功能说明

## 概述

本程序已成功集成游资大佬陈小群的选股策略逻辑，可以通过学习陈小群的选股方法来优化自身的策略评分系统。

## 陈小群核心策略

### 1. 龙头战法（20%权重）
- **核心思想**：追涨龙头股，强者恒强
- **量化指标**：
  - 龙头评分（板块排名、市值、流通盘）
  - 是否龙头股（板块排名前3）
- **评分规则**：
  - 板块排名1-3：90-99分
  - 板块排名4-10：70-89分
  - 板块排名11-30：40-69分
  - 板块排名30+：40分以下

### 2. 连板妖股因子（25%权重）
- **核心思想**：关注连续涨停的妖股
- **量化指标**：
  - 连续涨停天数
  - 是否妖股（5连板以上）
- **评分规则**：
  - 7连板以上：99分（超级妖股）
  - 5-6连板：90-98分（妖股）
  - 3-4连板：70-89分（强势股）
  - 1-2连板：60-79分（涨停股）
  - 未涨停：0-30分

### 3. 市场情绪因子（15%权重）
- **核心思想**：把握市场情绪周期
- **量化指标**：
  - 市场情绪周期（上升期/高潮期/退潮期/冰点期）
  - 情绪契合度
- **评分规则**：
  - 高潮期（连涨3天以上，5日涨幅>10%，量比>1.5）：85分
  - 上升期（连涨2天以上，5日涨幅>5%，量比>1.2）：75分
  - 退潮期（5日跌幅>5%或连跌2天以上）：25分
  - 冰点期（5日跌幅>10%）：10分

### 4. 资金流向因子（15%权重）
- **核心思想**：关注主力资金动向
- **量化指标**：
  - 主力资金净流入（万元）
  - 资金堆量程度
- **评分规则**：资金流入越多，评分越高（0-100分）

### 5. 打板策略因子（15%权重）
- **核心思想**：涨停板买入
- **量化指标**：
  - 涨停时机（早盘/中盘/尾盘）
  - 是否强势涨停（多次封板）
- **评分规则**：
  - 早盘涨停（10点前）：90分（最强势）
  - 中盘早涨停（10-11点）：80分
  - 午后涨停（11-13点）：60分
  - 尾盘涨停（13点后）：50分（相对较弱）

### 6. 高位接力因子（5%权重）
- **核心思想**：高位接力的勇气和判断
- **量化指标**：
  - 高位风险评分（基于20日均线偏离度）
  - 接力可行性评分
- **评分规则**：综合风险和可行性计算（0-100分）

### 7. 板块轮动因子（5%权重）
- **核心思想**：把握板块轮动节奏
- **量化指标**：
  - 板块热度
  - 板块轮动位置（启动期/发酵期/高潮期/分化期/退潮期）
- **评分规则**：
  - 高潮期：85分
  - 发酵期：75分
  - 启动期：60分
  - 分化期：45分
  - 退潮期：30分

## 使用方法

### 1. 批量分析同花顺策略股票

点击"陈小群分析"按钮，系统将：
1. 分析同花顺策略中的所有股票
2. 应用陈小群的7个核心策略因子
3. 生成陈小群风格的操作建议
4. 保存学习记录到数据库

### 2. 查看分析结果

分析完成后，系统将展示：
- **统计概览**：龙头股数量、妖股数量、高分股数量、平均评分
- **陈小群策略建议**：基于陈小群策略的操作建议
- **股票评分详情**：每只股票的7个维度评分和综合评分

### 3. 操作建议

- **综合评分 >= 80分**：强烈推荐 - 龙头+妖股，符合陈小群核心策略，建议打板买入
- **综合评分 70-79分**：推荐 - 具备龙头潜力，可考虑分仓买入
- **综合评分 60-69分**：关注 - 有涨停潜力，等待确认信号
- **综合评分 50-59分**：观望 - 特征不明显，暂不介入
- **综合评分 < 50分**：回避 - 不符合陈小群策略，建议放弃

## API接口

### 1. 单股分析

```http
POST /api/chen-xiaoqun/analyze
Content-Type: application/json

{
  "code": "600519",
  "name": "贵州茅台",
  "industry": "白酒"
}
```

### 2. 批量分析

```http
POST /api/chen-xiaoqun/batch-analyze
Content-Type: application/json

{
  "strategyType": "5day-trend"
}
```

### 3. 查询学习记录

```http
GET /api/chen-xiaoqun/analyze?code=600519
```

## 数据库表

### chen_xiaoqun_learning_records

存储陈小群策略学习记录，包含以下字段：
- 龙头战法因子（dragon_head_score, is_dragon_head）
- 连板妖股因子（consecutive_limit_up, is_monster_stock）
- 市场情绪因子（market_sentiment_cycle, sentiment_alignment）
- 资金流向因子（main_force_flow, fund_accumulation）
- 打板策略因子（limit_up_timing, limit_up_strong）
- 高位接力因子（position_risk, relay_feasibility）
- 板块轮动因子（sector_heat, sector_rotation_position）
- 综合评分（overall_score）
- 操作建议（action_advice）

## 陈小群策略核心要点

1. **龙头战法**：只做龙头，不做跟风
2. **妖股战法**：5连板以上可追，强者恒强
3. **情绪周期**：高潮期大胆出击，冰点期空仓等待
4. **资金流向**：跟随主力资金，不逆势而为
5. **打板策略**：早盘涨停最强，多次封板更可靠
6. **高位接力**：风险控制第一，理性判断接力
7. **板块轮动**：把握热点板块，抓住板块龙头

## 注意事项

1. 本系统学习的是陈小群的选股策略逻辑，不构成投资建议
2. 实际操作中应结合市场实际情况和自身风险承受能力
3. 所有数据均为模拟或实时数据，请以实际情况为准
4. 建议在模拟环境中充分测试后再实际应用
